# SG4 - Understanding Classes and Objects
## Music Genre
## My class represents the diverse genre that is popular in different generations.

## Properties
| Property | Data Type | Description |
|---|---|---|
| artist | string | Name of singer |
| genre | string | Type of music category|
| streams | int | Number of streams per month |
| title | string | Name of song |

## Methods
| Method | Description |
|---|---|| | |

| updateStreams(amount: int)| Displays the amount of streams per month by the selected artist|
| displayInfo(Selected_artist) | Displays the info by the selected artist |
| displayGenre(Selected_song) | Displays the kind of genre by the selected song |
| displayTitle(Selected_song) | Displays the title of the selected song |

## Design Explanation

### Why did you choose this class?
I chose this class because music has been a part of my hobby ever since I was little, and I also personally think that this is easier than any of the choices given-- even if I also have the option to create my own.

### Which property is the most important? Why?
In my opinion, the most important property is the artist. It is because a song cannot be created without the creator-- which is the artist. Eitherway, we can also gather info in what kind of genre that certain artist  produces.

### Which method is the most useful? Why?
The most useful method for me is the displaying of info of the selected artist. It is because this may already display the songs that the artist produces, and the general information that you may need sooner or later.
